p5.js addon · v0.5.0

Chalks.

A thin, independent library on top of p5.js for generative art: a fluent path builder, parametric curves and strange attractors, point layouts, a masonry grammar, a rule-based generative engine, and a small particle system — with color handled by chroma.js. Every canvas below is running live, real chalks code, right now, in your browser.
